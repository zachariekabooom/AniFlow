# Identité visuelle AniFlow

## Logo approuvé

- `aniflow-logo-final.png` est la référence visuelle approuvée par l'utilisateur.
- Le symbole associe un torii blanc, un petit livre/bibliothèque, un bouton lecture bleu électrique et un chemin bleu sur fond bleu marine très foncé.
- Conserver cette direction minimaliste ; ne pas réintroduire les anciens concepts ou choisir un autre logo sans demande explicite.
- Palette de départ : fond marine `#080D1A` / `#0B1020`, blanc cassé, gris bleuté pour les textes secondaires, bleu électrique comme accent. Les valeurs exactes peuvent évoluer avec le thème UI, sans perdre le contraste.
- Le fichier PNG est une référence raster. Si l'application exige plusieurs résolutions ou une transparence, produire des variantes dérivées proprement et documenter le procédé ; ne pas prétendre que l'image est vectorielle.
